# Context index

One line per file. Read in this order if you are new: `what-is-expected.md`, `challenge-digest.md`, `trusted-project.md`, then `../team/plan.md`.

## In context/

| File | What it is | Read when |
|---|---|---|
| `what-is-expected.md` | What the organisers expect from us, in plain words, with where the points are (written by us) | First, if you are new |
| `challenge-digest.md` | One-page summary of the whole challenge (written by us) | Always |
| `trusted-project.md` | What the real TrustED project builds and how its evaluators think (researched 2026-11-06) | Before choosing the pitch and the scenario |
| `scenarios-at-a-glance.md` | The 27 sharing scenarios in one table | Shortlisting a scenario |
| `pets-eval-howto.md` | Install and use the organisers' scoring toolkit | Setting up, and before every scorecard run |
| `organiser-reply-2026-11-07.md` | The organisers' answer to our questions: one scenario is enough, explain the trade-offs, measure, state what is not achieved (verbatim) | Before deciding scope or writing the pitch |
| `brief.md` | The official 8-section challenge brief, converted | You need the exact wording of the task or judging |
| `brief-onepager.md` | The official one-page challenge sheet | You need the five required demo items or the PET list |
| `video-transcript.md` | Transcript of the organiser video | Optional, for tone and emphasis |
| `source-files.md` | List of the organiser zip contents with sizes and hashes | You need to find or verify an original file |
| `proving-ground/` | 29 verbatim organiser docs (see below) | Choosing a dataset, scenario or PET; reading the metrics |
| `originals/` | The unconverted organiser files (docx, pdf) and where the video lives (release asset) | You distrust a conversion or need the video (the data zip is never published) |
