# Context index

One line per file. Read in this order if you are new: `challenge-digest.md`, then `../team/plan.md`.

## In context/

| File | What it is | Read when |
|---|---|---|
| `challenge-digest.md` | One-page summary of the whole challenge (written by us) | First, always |
| `brief.md` | The official 8-section challenge brief, converted | You need the exact wording of the task or judging |
| `brief-onepager.md` | The official one-page challenge sheet | You need the five required demo items or the PET list |
| `video-transcript.md` | Transcript of the organiser video | Optional, for tone and emphasis |
| `source-files.md` | List of the organiser zip contents with sizes and hashes | You need to find or verify an original file |
| `proving-ground/` | 29 verbatim organiser docs (see below) | Choosing a dataset, scenario or PET; reading the metrics |

## In team/

| File | What it is | Read when |
|---|---|---|
| `../team/plan.md` | Schedule, roles, demo requirements, open questions | Planning the weekend |
| `../team/submission-checklist.md` | Fields and checks for the sinceai.app submission | Before and on Sunday morning |

| File | What it is | Read when |

## Where the proving-ground docs are

Copies live in `context/proving-ground/` now. The same files sit in `data/proving-ground/` once the data is restored. After restore, `data/proving-ground/` is the authoritative one.

Start with `proving-ground/START_HERE.md`, then `docs/SCENARIOS.md`, `docs/PET_PLAYBOOK.md`, `docs/EVALUATION.md` and `docs/BENCHMARK.md`.
