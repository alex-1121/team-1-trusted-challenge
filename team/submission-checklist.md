# Submission checklist - sinceai.app, Sunday 8 November 10:00 Turku time

Hard deadline. The platform, not Devpost. Source: the organiser builder guide on sinceai.ai and `../context/brief.md` section 07.

## Required fields

- [ ] Project name (80 characters)
- [ ] One-sentence tagline (140 characters). It is the first thing voters see on the vote card
- [ ] Description (5,000 characters): data types identified, PET choices, protected output, measured before/after utility, one realistic sharing scenario, honest limitations
- [ ] Built with (tech chips, five show on the vote card)
- [ ] Repository link (public, no data files, no secrets, no `rowmap_*.csv`, `truth/` or `holdout/`)
- [ ] Demo video: public or unlisted YouTube link, ideally under two minutes, English narration recommended. YouTube is the only accepted format
- [ ] Source code zip, up to 100 MB, without node_modules or data files

## Optional

- [ ] Demo URL
- [ ] Pitch deck
- [ ] Up to two supporting documents (the scorecard HTML is a natural one)

## Before pressing submit

- [ ] A fresh clone of the repo runs the demo from the README
- [ ] The video shows all five required demo items
- [ ] Attribution line present: "TrustED PETs Proving Ground 2026, synthetic data by Since AI ry (CC BY 4.0)"
- [ ] No real personal data, no secrets, no em-dash anywhere public
- [ ] Every number in the description matches a scorecard run that is committed as JSON
